# UE5 Study

-   **몬스터 생성**
    
    -   몬스터를 랜덤 위치에 생성한다.
        
-   **기본 상태: 정찰(Patrol)**
    
    -   랜덤 위치를 설정한다.
        
    -   해당 랜덤 위치에 도달할 때까지 이동한다.
        
    -   도착하면 새로운 랜덤 위치를 다시 설정한다.
        
-   **플레이어 감지**
    
    -   플레이어가 몬스터 기준 **1000 거리 이내**에 있는지 확인한다.
        
-   **상태 전환**
    
    -   플레이어가 **1000 거리 안에 들어오면 → 추적(Chase)**
        
        -   플레이어 방향으로 이동하며 추적한다.
            
    -   플레이어가 **1000 거리 밖이면 → 정찰(Patrol)**
        
        -   랜덤 위치를 목표로 이동한다.
            
-   **정찰 동작**
    
    -   랜덤 위치 설정
        
    -   해당 위치 도달 시까지 이동 유지
        
    -   도착 후 새로운 랜덤 위치 재설정
